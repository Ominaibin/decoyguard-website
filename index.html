01 / The framework

DON’T JUST DEFEND.
DECEIVE.

Give suspicious activity somewhere else to go.

DecoyGuard combines honeypot deception with log-based behavioural detection. It helps security teams observe unauthorized interactions and investigate the evidence they leave behind.

Installation notes

Install Python and the dependencies supplied with the verified DecoyGuard release. Install Docker Desktop if using containerized lab applications, and install Playwright Chromium when required by the mirroring engine.

Configure the test-site gateway addresses locally, then start the application using the command provided by your release. Only test systems you own or are authorized to assess.

Exact commands and downloadable files should be checked against the final release package before publishing.
