INSTALLATION

FROM DOWNLOAD TO FIRST RUN.

Extract the ZIP, open the extracted decoyguard folder in a terminal and follow the steps for your operating system.

PythonDocker + ComposeInternet connectionAuthorized test environment
Windows / PowerShell

01 — Prerequisites

Install Python 3.14 and Docker Desktop. Finish Docker Desktop’s WSL 2 setup and make sure Docker is running.

02 — Install dependencies and browser

py -3.14 -m pip install -r requirements.txt
py -3.14 -m playwright install chromium

03 — Start the local application

py -3.14 decoyguard.py --dashboard-only

Open the local address printed in the terminal, configure your account and use Website Handler to add your authorized source website. Keep the engine running during testing.

04 — Resume later

py -3.14 decoyguard.py --saved
Linux / Ubuntu

01 — Prerequisites

Install Docker Engine, its Compose plugin and Python environment support. On Ubuntu, install python3-venv if needed.

02 — Install dependencies and browser

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install --with-deps chromium

03 — Start the local application

.venv/bin/python decoyguard.py --dashboard-only

Use Website Handler to add an authorized website. To resume a configured installation, run:

.venv/bin/python decoyguard.py --saved
This source package starts without preconfigured mirrors or saved accounts. The live Juice Shop and Banking demonstrations run separately on our demonstration server. Your local installation does not connect to that server automatically.
